# M5: local masked replay

Run **Scrubline: Export masked replay** in a trusted workspace or expand Replay in the panel. Review the privacy notice, then choose a destination folder. Scrubline makes a new folder containing index.html, metadata.json and PNG frames. Copy that whole folder to another device and open index.html. No server, uploads, telemetry or project code is in the playback page.

The default export is deliberately a **masked layout**, not the original screenshots. Original screenshot pixels cannot be reliably redacted by string replacement. The exporter observes only a bounded set of layout boxes, then draws new neutral rectangles on an isolated canvas. All text, media, source, filenames, paths, URLs, prompts, timestamps and hook payloads are omitted. Metadata contains only ordinal frame numbers, fixed relative image paths and hashes of masked geometry. Geometry can still reveal layout structure; review before sharing. Historical rendering runs the user's configured local preview command, just like preview; it is not an OS sandbox. No hosted sharing or remote access model is implemented.

The exporter stops if a historical state cannot render. It never silently substitutes a later state. It uses a separate preview port (configured port + 3), keeps source read-only, cleans failed output and preserves existing destination files. Limits: 200 checkpoints, 50 MB image total, 500 visible boxes per frame, 960×600 viewport. No original cached screenshot is exported. Missing dependencies can prevent historical rendering.

Playback has Prev/Next, seek, Play/Pause and keyboard focus. Only one image is mounted for a large timeline. A short fade is permitted only when masked geometry is exactly identical; different identities switch instantly. Reduced-motion disables fade. This identity rule does not claim component or DOM semantic mapping. The page uses system fonts with Geist first if installed, with no remote font request.

Automated checks cover portable offline file opening after moving the folder, no network requests, masked output from a secret-bearing fixture, reduced-motion, bounded 200-frame DOM, export failure/invalid-image cleanup, panel routing, and existing history/restore safeguards. Desktop and mobile screenshots are rendered evidence. Human checks: copy the folder to a second physical device, verify local file access there, review layout privacy, test the user's Antigravity host. Remote revocation is not applicable to a local folder; any future hosting requires explicit service/access/expiry/deletion approval.
